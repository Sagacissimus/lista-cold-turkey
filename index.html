Lista de bloqueo de sitios para adultos

Unos 18 000 sitios, listos para añadir a Cold Turkey Blocker en Windows o Mac.

1 · Descargue la lista

Hágalo desde la computadora donde tiene instalado Cold Turkey.

2 · Añádala a Cold Turkey

  1. Abra Cold Turkey Blocker y vaya a la pestaña Blocks.
  2. Cree un bloqueo nuevo (por ejemplo, «Contenido adulto») o abra uno que ya tenga para editarlo.
  3. En la lista de sitios web, pulse Import › Websites from file… y elija el archivo lista-cold-turkey.txt que descargó.
    ¿Usó «Copiar la lista»? Pegue el texto directamente en la lista de sitios web del bloqueo.
  4. Guarde, inicie el bloqueo y active el candado (Lock): así no podrá desactivarse antes de tiempo.
Actualícela cada pocos meses. Cold Turkey no actualiza la lista por sí solo, y cada semana aparecen sitios nuevos. Esta página siempre ofrece la versión más reciente: descárguela de nuevo e impórtela en el mismo bloqueo. Si el bloqueo tiene el candado activado, tendrá que esperar a que termine para poder editarlo.
Consejo: si nota que la computadora o el navegador se vuelven lentos, quite la lista y use solo las categorías propias de Cold Turkey. Ninguna lista es completa: combínela con un filtro como CleanBrowsing.
