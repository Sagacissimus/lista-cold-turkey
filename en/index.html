Adult-site blocklist

About 18,000 sites, ready to add to Cold Turkey Blocker on Windows or Mac.

1 · Download the list

Do this on the computer where Cold Turkey is installed.

2 · Add it to Cold Turkey

  1. Open Cold Turkey Blocker and go to the Blocks tab.
  2. Create a new block (for example, “Adult content”) or open an existing one to edit it.
  3. In the list of websites, click Import › Websites from file… and choose the file lista-cold-turkey.txt you downloaded.
    Used “Copy the list”? Paste the text straight into the block’s list of websites.
  4. Save, start the block and turn on the lock (Lock) so it cannot be turned off early.
Update it every few months. Cold Turkey does not update the list by itself, and new sites appear every week. This page always offers the latest version: download it again and import it into the same block. If the block is locked, you will have to wait until the lock ends before you can edit it.
Tip: if the computer or browser becomes slow, remove the list and use only Cold Turkey’s own categories. No list is complete: combine it with a filter such as CleanBrowsing.

Source: the “nsfw small” list from oisd.nl, version: the latest, distributed under the GPL-3.0 licence. The original list and its code are at github.com/sjhgvr/oisd. The list is downloaded straight from the source when you click the button; only the comment lines are removed.
